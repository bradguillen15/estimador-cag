# Sample: gym bookings (Web / SaaS)

Suggested form options: **Web / SaaS** · **Medium** · **Phases table** · language **Español**.

Copy everything below the line into *Descripción del proyecto*.

---

Necesitamos un MVP web de reservas para un gimnasio: los socios eligen clase, horario y entrenador; hay lista de espera, recordatorios por email y un panel admin para crear horarios y ver asistencia. Login con email/contraseña, pagos con Stripe (mensualidad), y debe funcionar bien en móvil. El equipo es pequeño (2–3 personas) y queremos salir en unas 8–10 semanas.
