# Sample: delivery courier app (Mobile)

---

iOS and Android app for courier drivers: they receive assigned orders, navigate with an in-app map, mark packages as delivered, and upload a photo of the drop-off. Push notifications for new jobs, basic offline sync when signal is poor, and a small ops web panel to assign routes and view live status. We already have a REST API for orders; we need the mobile clients and the ops panel. Target launch in about 12 weeks with a team of 4.
